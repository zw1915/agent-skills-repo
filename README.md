# WorkBuddy 咨询级 Agent Skills

共 **165** 个专业级技能，遵循开放 [SKILL.md](https://agentskills.in) 标准，可直接用于 Claude Code / Codex CLI / ChatGPT / WorkBuddy 等支持 SKILL.md 的 Agent。

## 安装

单技能安装（任选其一）：

```bash
# 通过 SkillsMP / skills CLI
npx skills add <owner>/agent-skills-repo

# 或直接下载
curl -O https://raw.githubusercontent.com/<owner>/agent-skills-repo/main/skills/<slug>/SKILL.md
mkdir -p ~/.claude/skills/<slug> && mv SKILL.md ~/.claude/skills/<slug>/
```
