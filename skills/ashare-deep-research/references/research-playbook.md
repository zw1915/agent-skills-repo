# 六段式投研操作手册

> 每一段都必须回答本段规定的**唯一核心问题**。答不出就如实标注，
> 绝不允许用"整体来看……未来可期"这类无信息量的句子填充。

---

## 第一段 · 结论先行

**核心问题：如果只能留一句话给读者，是哪句？**

格式要求：

1. 一句话定性（必须落在"买入/持有/观望/回避"的四档之一 + 修饰词）；
2. 三条互相咬合的核心事实——三条之间要有因果或并列逻辑，不能是三条孤立的常识；
3. 一段引用块，复述本次判断最反直觉的那一处。

**反向测试**：把这三条事实给一个不看报告的人，看他自己能不能推到同一个结论。不能，说明没提炼到位。

---

## 第二段 · 基本面

**核心问题：报表显示的经营状况，和剔除一次性因素后的真实状况，差多少？**

必做动作：

- **拆分一次性 vs 经常性**：减值、资产处置、政府补助、汇兑损益、股权激励费用，逐项剥离并做还原测算。这是本阶段最高价值的动作。
- **现金流交叉验证**：经营现金流 vs 净利润。剪刀差巨大时，先想"是不是非现金支出（减值/折旧）"，再想"是不是收入质量有问题"。
- **资产负债表体检**：资产负债率、流动比率、有息负债规模。判断这家公司**会不会死**——这决定了下跌时能否扛得住。
- **估值双重口径**：报表口径 PE/PB 与还原口径 PE/PB 并列呈现。

必须列出的信息缺口（常见）：

| 缺口 | 影响 |
|---|---|
| 扣非归母净利 | 无法确认利润是否为纯经营性 |
| 一次性损益的分季度归属 | 单季拆解只能是推算 |
| 营收增长的分业务/分地区驱动 | 无法验证增长持续性 |
| 研发资本化率变化 | 利润可能被资本化美化 |
| 应收账款周转天数变化 | 收入质量风险 |

## 第三段 · 技术面

**核心问题：价格在结构上处于什么位置，赔率如何？**

必做读数（脚本已自动计算，写作时引用 stdout 输出）：

| 维度 | 判读规则 |
|---|---|
| 均线排列 | 多头排列=趋势修复；**乖离率是风险的直接度量** |
| MA60 乖离 | >+15% 属回归压力区；>+25% 极端危险 |
| MACD | 零轴上方金叉=中期动能确认；零轴下方=反弹性质 |
| RSI(14) | >70 超买 / <30 超卖；中性区不代表安全 |
| KDJ 的 J | >90 深度超买（短线最后一推）；<10 深度超卖 |
| ATR(14) | **最重要的风控参数**。>5% 日均波动必须放宽止损 |
| 量能倍数 | vs MA5/MA20/MA60。放量不涨=滞涨，缩量回踩=健康 |

必做结构分析：

1. **斐波那契回撤**：找主升段的低点→高点，计算 38.2% / 50% / 61.8% / 78.6%。61.8% 通常是牛熊分界。
2. **波段低点/高点**：标注最近一次转向的位置，作为结构性支撑/阻力。
3. **量价背离检测**：价格新高而量能萎缩，或价格反弹而资金净流出，都要显式点出。

> 均线有四种，趋势只有一种。指标冲突时，服从**更大周期 + 更大成交量**的那个。

## 第四段 · 新闻与事件面

**核心问题：最近 3 个月发生了哪些改变公司价值的事件，哪一件的权重最大？**

按以下优先级扫描，命中即重点写：

- **P0**：业绩预告修正、重大减值、管线/核心产品终止、审计意见变化、实控人变更、立案调查
- **P1**：股东减持（尤其是 5% 以上股东）、增发/可转债解禁、质押变动、大宗折价交易、董事会变动
- **P2**：订单中标、产能投放、新产品获批、行业政策

**事件要标价权**：不要罗列，要给出"这件事值多少钱 / 影响几条年利润"。写不出量化影响，就写"影响不可量化，但改变了 X 预期"。

**特别注意 —— 大宗交易席位分析法**（本方法论的高价值组件）：

同一卖方营业部连续多笔、深度折价出货，且买方分散到众多小席位，是**集中筹码系统性派发**的典型形态。
检查清单：

1. 卖方是否高度集中于单一营业部？
2. 折价率是否逐次扩大？（如 12% → 22%，说明出货意愿转急）
3. 近 3 个月累计成交笔数与金额量级？
4. 买方是否出现机构专用席位净买入？（有机构接盘≠安全，但至少说明有对手盘）
5. 同期是否有股东减持公告？——**大宗派发与股东减持同时出现，几乎不可能是巧合。**

## 第五段 · 情绪与筹码面

**核心问题：谁在买，谁在卖，他们的成本在哪里？**

必查项目：

| 项目 | 看多信号 | 看空信号 |
|---|---|---|
| 换手率 | 低位放量启动 | 高位持续 15%+ = 击鼓传花 |
| 自由流通股本占比 | 占比低=易驱动 | 占比低=也易崩塌，双向放大 |
| 融资余额 | 温和上升 | 单周降幅 >10% = 杠杆撤离 |
| 主力资金净流入 | 持续净流入 | 上涨中净流出=派发 |
| 股东户数 | 减少=筹码集中 | 增加=筹码分散，通常不利 |
| 龙虎榜 | 机构专用净买入 | 游资席位接力 |

**关键心法：把对手盘的成本算出来。**
当大宗交易的机构接盘价与现价几乎持平时，这批筹码在破位时会成为**新增卖压**，而不是支撑。

## 第六段 · 多空辩论

**核心问题：如果我在这个位置错了，最可能是因为什么？**

规则（违反了这一段就形同虚设）：

1. **各写三条最强论据，且强度对等。** 写不出的那一方，说明你还没研究透。
2. **三条之间不得重复**，要覆盖公司质地、筹码结构、估值/技术三个不同层面。
3. **裁决必须指出双方各自"赢"在哪一维**。真实的情况往往是：多头赢在公司，空头赢在筹码；或多头赢在空间，空头赢在时间。这种"分层裁决"比简单的"偏向多方"有价值得多。
4. 裁决之后必须落到**时间成本**判断：凝聚/消化可能持续多久，值不值得等。

## 第七段 · 交易计划与风控（决定了这份报告有没有用）

### 价位表

必须给出：阻力 2 档、支撑 3~4 档，每档标注**依据**（回撤位/均线/前高前低/成交密集区），不能凭感觉出题。

### 分场景

固定四种情形，缺一不可：

| 场景 | 触发条件 | 动作 |
|---|---|---|
| 突破跟进 | 放量站稳 X 且回踩不破 | 仓位上限、止损位 |
| 回踩吸纳 | 缩量回踩 X 区间止跌 | 分批方式、止损位 |
| 破位离场 | 有效跌破 X | 无条件退出 |
| 已持有者 | — | 减仓/止损上移建议 |

### 仓位与止损（必须基于 ATR）

```
止损宽度 ≥ 1.5 × ATR(14)
单笔最大亏损 = 账户资金 × 风险预算(建议 1%)
最大持仓市值 = 单笔最大亏损 ÷ 止损百分比
```

**务必给出具体金额示例**（如账户 100 万时的持仓市值与占比），否则读者无法执行。

**高波动折价**：当出现以下任一情形时，实际建仓额度再打 1/3 折：

- KDJ 的 J > 90
- ATR 占股价 > 6%
- 主力资金连续净流出
- 存在未出清的集中派发席位

### 失效信号

列出 5 条**可观测**的触发条件。写成"若 X 发生，本报告结论作废"。
这一项是专业研究与自媒体的分水岭。
