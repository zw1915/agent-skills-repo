# 首板因子手册（factor-playbook）

本文件回答三个问题：**每个因子怎么算**、**方向应该朝哪**、
**回测跑出来到底是什么样，以及怎么读它**。

所有因子的取值都在涨停日（T 日）盘后即可获得，不含任何未来信息。
`lu_event` 表里的 `t1_*` / `t2_*` 是前瞻收益字段，**只用于回测评估，
绝不进入打分**。

---

## 一、因子总表

| 键 | 中文 | 类型 | 方向 | 权重 | 先验逻辑 |
|---|---|---|---|---|---|
| `body_depth` | 日内回撤深度 | 连续·越小越强 | 负 | 0.20 | 从涨停价回落越浅，说明封板越实、抛压越小 |
| `vol_ratio` | 量能倍数 | 区间 1.5~4× | 适中 | 0.15 | 太小无人关注、太大常是高位放量出货 |
| `amount_yi` | 成交额（亿） | 区间 1~25 | 适中 | 0.10 | 太小流动性差易被闷杀，太大盘子重、次日溢价低 |
| `price` | 股价 | 区间 3~30 元 | 适中 | 0.10 | 太低有面值退市风险，太高散户参与度低、弹性差 |
| `prev_ret20` | 前 20 日涨幅 | 区间 -10%~25% | 适中 | 0.15 | 不追高：已拉升的票次日溢价被提前透支 |
| `pos60` | 60 日位置 | 连续 | 正 | 0.15 | 创新高（≈1.0）代表无套牢盘，突破形态 |
| `is_first` | 首板标记 | 二值 | 正 | 0.15 | 首板 > 连板：连板次日不确定性大、且监管关注度高 |

权重是**先验设定，不是样本内拟合**（见 `strategy.py` 顶部注释）。
回测的分层结论用于**验证方向**，而不是反过来调权重。

### 字段口径（`lu_event` 表）

| 字段 | 含义 | 备注 |
|---|---|---|
| `body_depth` | `(涨停价 − 收盘价) / 昨收` | 一字板≈0；封板打开过则 >0 |
| `gap_open` | `(今开 − 昨收) / 昨收` | 竞价强度 |
| `vol_ratio` | 当日量 / 前 5 日均量（不含当日） | 放量倍数 |
| `amount_yi` | 当日成交额（亿元） | |
| `turnover` | 换手率（%） | 数据源口径，部分年份缺失 |
| `price` | 当日收盘价（元） | |
| `prev_ret20` | 前 20 个交易日累计涨幅（不含当日） | |
| `pos60` | 收盘价 / 近 60 日最高收盘 | 涨停封在最高价时≈1.0 |
| `prior_lu20` | 前 20 日涨停次数 | 用于首板判定 |
| `streak` | 当时连板数 | 首板 = 1 |
| `is_first` | 是否首板 | `prior_lu20 == 0` |
| `bars_listed` | 上市以来交易日数 | 剔除次新 |
| `seal_minute` | 封板时间（分钟） | **日线拿不到，恒为 NULL**，见下节「近似说明」 |

## 二、打分与分档机制

### 1. 区间型因子用 `band_score`

量能、成交额、价格、涨幅四个因子是「适中最好」，不是「越大越好」。
`band_score(x, lo, hi, soft)`：

- `x ∈ [lo, hi]` → 得 1 分；
- 越出区间后，按 `soft` 线性衰减到 0，**不会变成负分**；
- `x` 缺失 → 给 0.5 的中性分（不奖不罚）。

理想带（`strategy.BANDS`）：

```
vol    1.5 ~ 4.0 倍   （soft 2.5）
amount 1.0 ~ 25 亿    （soft 8.0）
price  3.0 ~ 30 元    （soft 4.0）
prev  -10% ~ +25%     （soft 0.35）
```

### 2. 横截面秩次归一化

所有因子在**同一交易日内部**转成 0~1 的秩次，再按权重合成 0~100 的总分。
这样做的原因：不同日子的市场水位不同（牛市涨停 200 家、熊市 20 家），
绝对阈值会漂移；而打板是「在当天所有涨停里挑最强的」，本来就是相对比较。

> 注意：秩次归一化意味着**分数与市场整体强弱无关**。市场好坏由情绪闸门
> （仓位）单独处理，两者分工明确，不要混在一起。

### 3. 封板强度的近似说明（重要）

日线数据**拿不到封板时间和封单量**——那需要分时或盘口数据。
本策略用两个可观测特征近似封板强度：

- **开盘即涨停**（`gap_open` 达涨停幅度）→ 一字板/T 字板；
- **日内回撤深度** `body_depth`：从涨停价回落越浅越强。

`shape` 分档：`一字板` / `T字板` / `浅回撤`（≤3%）/ `深回撤`（>3%）。
**不要把这个近似等同于真实封单强度**，它只是一个朝正确方向的代理变量。
若后续接入 Level-2 或分时数据，应优先替换这一项。

## 三、硬性剔除规则（`hard_filters`）

在打分之前先剔除，避免「打分把不该买的也排进前十」：

| 规则 | 阈值 | 理由 |
|---|---|---|
| 非首板 | `is_first == 0` | 本策略只做首板 |
| 一字板 | `shape == "一字板"` | 次日大概率一字开盘，买不到 |
| 低价股 | `price < 2.0` | 面值退市风险 |
| 成交额 | `amount_yi < 0.5` | 流动性不足易被闷杀 |
| 次新股 | `bars_listed < 60` | 无历史形态参考、上市初期波动异常 |
| 已拉升 | `prev_ret20 > 60%` | 涨幅过大，次日溢价透支 |
| 连板 | `streak > 1` | 与「非首板」互为兜底 |

## 四、市场情绪闸门（`market_regime`）

情绪**不参与选股**（它对当日所有股票相同），只决定**总仓位**——
这是这类策略最有效的一道风控。

主判据是 `yest_lu_premium`（昨日涨停股今日平均涨幅），它是**个股级收益率**，
与股票池大小无关；`lu_count` 只作辅助确认，且阈值按股票池规模缩放
（以约 5000 只全市场为基准）。

| 档位 | 条件（示意） | 建议仓位 |
|---|---|---|
| 进攻 | 溢价 > +2% 且涨停家数多、最高板 ≥4 | 100% |
| 平衡 | 溢价 > 0 且涨停家数尚可 | 60% |
| 防守 | 溢价 > -3% | 30% |
| 空仓 | 溢价 ≤ -3% | 0% |
| 冰点 | 涨停家数极少且溢价 ≤ 0 | 0% |

### 5.3 怎么读这张表

- **号**：`body_depth` 是负向因子（越小越强），若「最高组」反而收益高，
  说明近似封板强度的代理没起作用，应重新审视形态分档。
- **单调性**：1.0 表示各层收益完全单调。区间型因子（量能/成交额/价格/涨幅）
  理想形态是**中间高两头低**，此时单调性会偏低——这是正常的，不代表因子无效。
- **IC 均值**：日均 Spearman 秩相关。打板因子单个 IC 通常不高（0.02~0.06），
  能稳定为正且 ICIR > 0.3 就算可用；不要期待 alpha 因子的 IC 量级。
- **样本量**：单层样本 < 100 时结论不可靠，本表在 12 年全市场上应远超此线。

## 六、局限与后续可改进项

1. **封板强度是近似**（日线口径限制），接入分时/Level-2 后可显著提升。
2. **权重为先验**，未做样本内优化；若要调参请用 `backtest.py --oos` 做样本外验证。
3. **换手率历史缺失**：部分年份数据源不提供，该因子在缺失年份给中性分。
4. **市值用快照**：`stock_meta` 的市值字段是抓取时点的，不能用于历史市值因子。
5. **ST 判定为推断**：由滚动波动特征推断 5% 制度，非官方 ST 名单。
