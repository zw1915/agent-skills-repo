# 分品类合规红线与高转化套路

同一句文案在不同品类下的合规结论可能完全相反，买家在意的东西也完全不同。**先定品类，再定红线，最后定写法**——这个顺序不能颠倒。

每个品类给出四块：监管定位 / 专属红线 / 必备提示语 / 决策路径与套路。

---

## 1. 普通食品 `food`

- **监管定位**：《食品安全法》《广告法》第 17 条。**无保健功能宣称资格**。
- **专属红线**：任何保健功能、疾病预防治疗、功效暗示。高频变相写法——「吃了不容易感冒」「调理肠胃」「改善体质」「增强抵抗力」「排毒」。
- **必备提示语**：无需强制，但不得出现「保健」「功效」「疗效」类表述。
- **决策路径**：口味 → 便利性 → 价格 → 配料表干净度 → 品牌。
- **套路**：口感场景前置（「办公室下午三点，开袋即食」）+ 配料表可视化（「配料只有 4 样：…」）+ 用量/份数换算（「一袋够喝 15 天」）。

## 2. 保健食品 `health_food` ⚠️ 强监管

- **监管定位**：《广告法》第 18 条。**仅可宣称注册/备案的保健功能**（现行 24 项）。
- **专属红线**：超出注册功能范围、涉及疾病预防治疗、暗示「治疗」「根治」。
- **必备提示语**（缺一即违规）：**「本品不能代替药物」** + 保健食品标志（蓝帽子）+ 适宜人群与不适宜人群 + 保健食品注册/备案号。
- **决策路径**：功效匹配自身需求 → 成分剂量 → 安全性/副作用 → 品牌信誉 → 长期成本。
- **套路**：功能对应真实需求场景 + 成分与剂量的可核验表达 + 服用方式与周期说明 + 蓝帽资质前置展示。**不做「效果对比图」类暗示**。

## 3. 普通化妆品 `cosmetic`

- **监管定位**：《化妆品监督管理条例》。**不得宣称医疗作用**。
- **专属红线**：祛斑、美白、防晒、防脱发、染发、烫发（这 6 类属特殊化妆品）、抗敏、修复受损屏障、祛痘（功效宣称需谨慎）、消炎抑菌。
- **高频变相写法**：「用了痘痘消了」「敏感肌救星」「修复角质层」。
- **必备提示语**：普通化妆品无强制，但成分与功效须与备案一致；不得暗示药效。
- **决策路径**：肤质匹配 → 成分（烟酰胺/玻尿酸/视黄醇等）→ 是否刺激 → 口碑 → 价格。
- **套路**：肤质场景前置（「干皮上妆卡粉的人」）+ 成分与浓度具体化 + 使用顺序与用量 + 真人使用感受（**不得用疗效前后对比暗示功效**）。

## 4. 特殊化妆品 `cosmetic_special` ⚠️

- **监管定位**：需国家药监局注册，取得注册证号。
- **专属红线**：宣称超出注册功效范围；无注册证号却宣称美白/祛斑/防晒/防脱。
- **必备提示语**：注册证号（如「国妆特字 G2023XXXX」）+ 不得超范围宣称。
- **套路**：同普通化妆品，但可合法使用「美白」「祛斑」等词，**仍须与注册功效表述一致**，不得延伸为「彻底祛除」「永久美白」。

## 5. 医疗器械 `medical_device` ⚠️ 强监管

- **监管定位**：《医疗器械监督管理条例》。需**医疗器械注册证号 + 广告审查批准文号**（医疗器械广告需省级药监审查）。
- **专属红线**：无批准文号发布广告；宣称治愈率、有效率；使用「根治」「彻底治愈」；扩大适用范围。
- **必备提示语**：注册证编号 + 广告审查批准文号 + 适用范围表述与注册证一致。
- **套路**：合规优先。只陈述注册范围内的用途、使用方式、注意事项；**不做效果承诺，不做与药品的类比**。

## 6. 母婴用品 `mother_baby` ⚠️

- **监管定位**：《广告法》第 40 条。
- **专属红线**：宣称替代母乳、使母乳化；利用不满十周岁的未成年人作代言；婴幼儿配方乳粉宣称益智/增智/提高智力/保护肠道；奶瓶奶嘴宣称「医用级」「食品级」而无检测依据。
- **必备提示语**：婴幼儿配方食品不得宣称益智；建议母乳喂养的提示（配方乳粉）。
- **决策路径**：安全性（材质/认证）→ 适龄性 → 使用便利 → 品牌 → 价格。
- **套路**：适龄段前置（「6-12 个月」）+ 安全认证具体化（「A 类婴幼儿标准 GB 31701」「FDA 认证材质」）+ 使用场景（「夜里冲奶不摸黑」）+ 家长真实顾虑回应。

## 7. 服饰鞋包 `apparel`

- **监管定位**：《广告法》。成分标注须与实际一致。
- **专属红线**：「纯棉」「100% 羊毛」「真丝」等成分宣称与实际不符（构成虚假宣传）；「抗皱」「防水」「防晒 UPF50+」需检测依据；「大牌同款」「原单」涉侵权。
- **必备提示语**：成分含量须可核验；功能性宣称（防晒、防水、抗菌）需检测报告。
- **决策路径**：款式/版型 → 面料手感 → 尺码准确性 → 退换保障 → 价格。
- **套路**：身材场景代入（「160/微胖/胯宽」）+ 面料成分数量化（「32 支精梳棉」）+ 尺码实测数据（肩宽/衣长/胸围表）+ 洗涤与保养 + 退换承诺。

## 8. 3C 数码 `digital`

- **监管定位**：《广告法》。
- **专属红线**：「充电 5 分钟通话 2 小时」类参数需注明测试条件；「快充」「闪充」需标协议与功率；跑分、续航、像素等对比需注明来源与条件；「军规级」「防水 IPX8」需认证依据。
- **必备提示语**：参数宣称须注明测试条件与来源；对比数据须注明基准。
- **决策路径**：核心参数 → 实际体验（发热/续航）→ 兼容性 → 售后 → 价格。
- **套路**：使用场景前置（「通勤两小时，电量从 20% 到 80%」）+ 参数带条件（实测条件标明）+ 兼容性清单 + 售后政策明确。

## 9. 家居日用 `home`

- **监管定位**：《广告法》。
- **专属红线**：「除甲醛」「抗菌」「防螨」「净化空气」需 CMA/CNAS 检测报告；「食品级」「医用级」需依据；「实木」与「实木颗粒板」须区分。
- **必备提示语**：功效类宣称须附检测报告编号与机构。
- **决策路径**：尺寸匹配 → 材质 → 安装/清洁便利 → 耐用性 → 价格。
- **套路**：空间场景代入（「3 平米小卫生间」）+ 尺寸与材质数据 + 检测报告展示 + 安装与清洁说明。

## 10. 宠物用品 `pet`

- **监管定位**：《广告法》《饲料和饲料添加剂管理条例》。
- **专属红线**：宠物食品不得宣称治疗功能（「治皮肤病」「驱虫」）；「处方粮」需兽药/饲料资质；「人类食品级」需依据。
- **必备提示语**：宠物饲料需生产许可证号。
- **决策路径**：适用宠物年龄/体型/品种 → 成分安全 → 适口性 → 品牌 → 价格。
- **套路**：宠物场景代入（「挑食的橘猫」）+ 成分表与营养指标 + 喂食量与周期 + 挑食应对说明。

## 11. 金融产品 `finance` ⚠️ 强监管

- **监管定位**：《广告法》第 25 条。
- **专属红线**：**保本、保收益、稳赚不赔、无风险、高回报、承诺收益区间**——绝对禁用。
- **处置**：本技能对该类目**仅做风险标注**，不提供卖点优化。明确告知用户：金融产品广告受持牌监管机构审查，请以合规部门意见为准。

## 12. 教育培训 `education`

- **监管定位**：《广告法》第 24 条；"双减"政策。
- **专属红线**：对升学、通过考试、获得学位作出明示或暗示的保证性承诺；利用受益者名义作证明；「保过」「包上本科」「XX 天速成」。
- **套路**：仅陈述课程内容、师资资质（可核验）、教学方式、试听政策；**不做效果承诺**。

## 13. 通用/其他 `general`

- **监管定位**：《广告法》通用条款。
- **处置**：只应用绝对化用语、效果承诺、虚假宣传等通用红线。
- **套路**：走 `references/rewrite-playbook.md` 的五步通用模型，结合产品本身的功能视角选择切入。

## 跨品类通用套路速查

**买家决策的五个普遍问题**（优化版应能回答其中至少三个）：

1. 这跟我有什么关系？（场景与痛点）
2. 凭什么相信？（证据：数据、检测、专利、资质）
3. 跟别家比好在哪？（差异点，**不得贬低同行**）
4. 万一不合适怎么办？（退换、质保、售后）
5. 现在为什么要买？（价格机制、库存、赠品——**须真实**）

**类目切换时的三条检查**：

- 换品类必须**重新确认红线**，不能沿用上一类的结论。
- 跨类表述是最高频的失误：食品抄了保健品的词，普通化妆品抄了特殊化妆品的词。
- 强监管类目（保健食品、医疗器械、金融、母婴）一律提示用户走主管部门审查。
