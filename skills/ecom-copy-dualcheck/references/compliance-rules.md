# 违禁词库与豁免规则

本文件是 `scripts/compliance_scan.py` 的规则来源，也是模型复核时的判定依据。**改词表必须两处同步**，否则脚本与人工判定会漂移。

## 一、风险分级定义

| 等级 | 含义 | 处置 |
|---|---|---|
| 🔴 **高危** | 法定禁用或有明确执法案例，直接构成违法风险 | 必须删除或改写 |
| 🟠 **中危** | 需提供证明材料方可使用，无材料即违规 | 补证或改写 |
| 🟡 **提示** | 视上下文可能被认定违规，需人工判断 | 复核后决定 |

判级原则：**看该表述是否可被验证**。可被验证的具体事实（「续航 12 小时（实验室 25℃）」）不违规；不可验证的优越性断言（「续航最久」）违规。这一条比背词表更根本。

## 二、分级词库

### A. 绝对化用语 🔴

**法条依据**：《广告法》第九条第(三)项——广告不得使用"国家级""最高级""最佳"等用语。

| 词组 | 典型词 | 替换方向 |
|---|---|---|
| 最高级系 | 最好、最佳、最强、最大、最优、最先进、最低、最便宜、最受欢迎、最优质、最高端、最专业、最权威、最有效、最快、最省、最全、最安全、最健康、最高级、最舒适、最时尚、最流行、最新 | **删除形容词，补具体优势**：「续航 12 小时，较上代提升 30%」「通过 SGS 检测（报告号 XXX）」 |
| 序数系 | 第一、第1、No.1、TOP1、排名第一、销量第一、全国第一、全球第一、行业第一、同类第一、全网第一、销量冠军、行业冠军、首选、首选品牌 | **改为带来源与时点的排名事实**：「2025 年京东 3C 类目销量 TOP10（来源：XX 数据，2026.01）」 |
| 独一系 | 唯一、独家、独一无二、绝无仅有、仅此一家、仅此一款、独家配方、独家技术、独家专利 | 有授权/专利可保留但**必须标证书号**：「专利号 ZL2024XXXXXXX」；无则删除 |
| 等级系 | 顶级、顶尖、极致、极品、至尊、巅峰、终极、王牌、王者、冠军品牌、领导者、领导品牌、领先品牌、全球领先、世界领先、国际领先、行业领先、国内领先、领跑、标杆、国家级、世界级、国际级、国宴级、军工级、医用级、药妆级、万能、全能 | **改为具体规格/材质**：「意大利头层牛皮」「316L 不锈钢」「A 类婴幼儿标准」 |
| 极限系 | 完美、无瑕、无可挑剔、无与伦比、史无前例、空前绝后、登峰造极、绝版 | 删除，或改为可量化的对比事实 |

> **「药妆」已被国家药监局明令禁止使用**（不存在"药妆"这一品类概念），属必删项，不是改写项。
> **「医用级」**非医疗器械不得使用，改具体材质标准。
> **「国家级」**需国家主管部门认定文件方可使用。

### B. 效果与承诺 🔴

**法条依据**：《广告法》第二十八条（虚假广告）、第二十四条（教育培训）。

| 类型 | 典型词 | 说明 |
|---|---|---|
| 无条件退款承诺 | 无效退款、无效退全款、不满意退款 | 需写明具体条件与期限，否则构成虚假承诺 |
| 零风险系 | 零风险、无风险、稳赚不赔、保本保息、躺赚、一夜暴富、高回报 | 金融类**绝对禁用** |
| 时效承诺 | 一次见效、立刻见效、当天见效、3天见效、立竿见影、药到病除、根治、彻底解决、永久、永不反弹、断根、永不复发 | 效果性时效承诺，无临床/检测依据即违规 |
| 效果保证 | 100%有效、绝对有效、保证有效、必瘦、必买、绝对安全、绝对无副作用 | 「绝对」类断言一律违规 |

### C. 医疗与功效宣称 🔴

**法条依据**：《广告法》第十七条——除医疗、药品、医疗器械广告外，禁止涉及疾病治疗功能；《化妆品监督管理条例》《食品安全法》。

| 类型 | 典型词 | 类别限制 |
|---|---|---|
| 治疗类 | 治疗、治愈、疗效、药效、消炎、消肿、止痛、抗病毒、抗肿瘤、防癌抗癌、降血压、降血糖、降血脂、助眠、改善睡眠、预防疾病 | 非药品不得使用 |
| 医疗用语 | 处方、临床验证（无资质）、械字号、药妆、医学级、修复受损屏障 | 需对应资质 |
| 化妆品功效 | 祛斑、美白、防晒、防脱发、染发、烫发 | **仅特殊化妆品可宣称**，需注册证号 |
| 杀菌抑菌 | 杀菌、抑菌、除菌、99.9%杀菌 | 需消毒产品资质（卫消证字） |
| 保健功能 | 增强免疫力、提高免疫力、辅助降血脂、缓解疲劳、改善睡眠、增加骨密度 等 24 项 | **仅保健食品可宣称**，需与注册功能一致 |

> **普通食品**：不得宣称任何保健功能或疾病预防治疗功能。常见变相写法需警惕：「吃了不容易感冒」「改善肠道」「调节体质」。
> **化妆品**：不得宣称医疗作用，「祛痘」「抗敏」「修复」也属功效宣称，需谨慎。

### D. 促销误导 🟠/🔴

| 典型词 | 级别 | 说明 |
|---|---|---|
| 全网最低、史上最低、全网底价 | 🔴 | 无据即虚假 |
| 仅此一天、最后一天、错过再无、明天恢复原价 | 🟠 | 若活动延续则构成欺诈，需与实际一致 |
| 清仓价、跳楼价、亏本甩卖、血亏 | 🟠 | 需真实，且不得与价格比较形成误导 |
| 假一赔十、假一赔万 | 🟠 | 需有明确承诺条款支撑 |
| 限量、限时（不实） | 🟡 | 数量/时间须真实可核 |

### E. 金融与投资承诺 🔴

**法条依据**：《广告法》第二十五条。

保本、保收益、稳赚、无风险、零风险、高回报、年化 XX% 以上、稳赚不赔、投资零门槛。**金融类目绝对禁用**，本技能对金融类目只做风险提示，建议以持牌机构合规审查为准。

### F. 迷信与涉政 🔴

| 类型 | 典型词 |
|---|---|
| 迷信 | 招财、转运、辟邪、开光、旺夫、改运、风水、命理、镇宅、招桃花 |
| 涉政/特权 | 特供、专供、军供、国宴、人民大会堂（借用）、国家级（非授权）、领导人同款 |
| 歧视 | 针对性别/地域/年龄/身体状况的贬损或暗示性表述 |

### G. 需证明材料 🟠

| 类型 | 典型词 | 需补什么 |
|---|---|---|
| 成分与工艺宣称 | 纯天然、无添加、零添加、纯手工 | 检测报告或执行标准编号；「零添加」实际已被认定为误导，建议直接删 |
| 认证类 | 权威认证、国际认证、欧盟标准、日本技术、德国工艺、国家专利、独家工艺 | 证书编号与发证机构 |
| 背书类 | 专家推荐、医生推荐、明星同款 | 授权文件；无授权即删 |
| 渠道类 | 原产地直供、厂家直销 | 需真实可核 |

### H. 程度词 🟠

效果显著、效果出众、显著、明显改善、大幅提升、极大改善、超级、超强、巨划算、白菜价。

**处置**：程度词本身不违法，但**无对比基准即构成引人误解**。改法是把程度换成数值——「效果显著」→「4 周后皮肤含水量提升 23%（n=32，实验室测试）」。

### I. 资质宣称 🟠

医疗器械、械字号、药字号、处方药、OTC、国药准字。

**处置**：非对应资质产品使用即构成虚假宣传。资质齐备者应标注证书编号。

## 二·补、品类等级调整（关键机制）

同一组词在不同品类下**等级不同**——这是本技能与通用敏感词工具的核心分野，实现于脚本的 `CATEGORY_ADJUST`。

| 词条类别 | 默认等级 | 品类覆盖 | 调整后 | 说明 |
|---|---|---|---|---|
| 化妆品功效宣称（美白/祛斑/防晒/防脱/染发/烫发） | 🔴 | `cosmetic_special` 特殊化妆品 | 🟡 | 可宣称注册功效，须与注册证一致并标注册证号 |
| 保健功能宣称（增强免疫力/改善睡眠等 24 项） | 🔴 | `health_food` 保健食品 | 🟠 | 可宣称注册功能，须与批件一致并标「本品不能代替药物」 |

**为什么这样设计**：如果特殊化妆品宣称「美白」也被判 🔴，运营就会认为工具不可信而弃用；但如果普通化妆品宣称「美白」不被判 🔴，就是漏报。**只有让等级随品类变化，两边的结论才都正确。**

**配套的必备提示语检查**（`REQUIRED`）：等级下调不等于放行，脚本会同时检查该品类的法定必标项，缺失即单独报警：

| 品类 | 必查项 |
|---|---|
| 保健食品 | 「本品不能代替药物」、注册/备案号、适宜与不适宜人群 |
| 医疗器械 | 注册证编号、广告审查批准文号 |
| 特殊化妆品 | 注册证编号 |
| 金融产品 | 风险提示 |

## 三、上下文豁免规则（降误报的关键）

**机械词表最容易被误报的就是这一类。** 以下情形出现时，不得判为绝对化用语：

| 命中词 | 豁免语境 | 处理 |
|---|---|---|
| 第一 | 第一人称、第一步、第一批、第一次、第一周、第一天、第一个月、第一年、第一版、第一代、第一课、第一梯队、第一阶段 | **豁免，不报** |
| 第一 | 第一时间 | 降为 🟡 |
| 最好 | 「最好是」「最好别」「最好不」——建议性副词，非自我宣称 | **豁免，不报** |
| 最 | 「最近」「最后」「最初」「最终」「最晚」（时间词，非自我评价） | 不命中，词表未收录单字「最」 |
| 最大 | 「最大承重」「最大功率」「最大容量」「最大尺寸」等**技术规格** | **豁免，不报** |
| 100% | 「100% 棉」「100% 羊毛」「100% 实木」「100% 山羊绒」——成分标注 | **豁免，不报**（属客观标准） |
| 独家 | 后接专利号/授权书编号 | 降为 🟡 |
| 最新 | 「最新消息」「最新公告」「最新动态」 | 降为 🟡 |

> **注意「第一周」「第一步」这类豁免**：它们本身是客观表述，但若整句构成效果承诺
> （如「第一周就能看到淡斑」），应由模型复核层判定违规——**豁免的是词，不是句**。

**判定实现**：豁免模式从命中词位置起**精确匹配**（`re.match` 于 `sentence[start:]`），
而非在整句中搜索。否则「销量第一，第一人称拍摄」里的前者会被后者连带豁免。

**反向规则**：豁免是**降级而非免罪**。若整句仍在宣称优越性（「最好的服务，最好别犹豫」），应按原级处理。

## 四、替换方法论：从形容词到可验证事实

这是合规改写真正的难点——不是删词，是**把空断言换成能站住的事实**。四种转换路径：

| 路径 | 违规原句 | 合规改写 |
|---|---|---|
| **补测试条件** | 续航最强 | 续航 12 小时（实验室 25℃、50% 亮度条件下） |
| **补对比基准** | 比普通款快 3 倍 | 充电速度较本店上一代提升 3 倍（内部实测，样本 n=20） |
| **补材料来源** | 销量第一 | 2025 年天猫 XX 类目销量 TOP10（数据来源：生意参谋，2026.01） |
| **换维度描述** | 顶级面料 | 意大利头层小牛皮，厚度 1.2mm |
| **彻底删除** | 完美无瑕的工艺 | （删）——无可量化支撑则删，不要硬凑 |

**不可替换的项**：跨类功效宣称（食品说疗效）、医疗用语、金融承诺。这些必须整句删除或改述主张，不能靠换词过关。
