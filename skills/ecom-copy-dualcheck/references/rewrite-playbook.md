# 卖点重构方法

「合规版」与「优化版」是两条不同的路径——前者做减法，后者做重排。混为一谈会导致用户拿到两稿却看不出差别。

| | 合规版 | 优化版 |
|---|---|---|
| 手法 | 最小改动，只处理违规点 | 结构重排，重新组织表达顺序 |
| 保留 | 原文结构、语气、卖点顺序 | 卖点素材本身，结构可推翻 |
| 目标 | 能上架 | 能转化 |
| 篇幅 | 与原文相当 | 可增减，但不得新增无据信息 |

---

## 一、五步重构法

**痛点前置 → 场景代入 → 证据支撑 → 信任背书 → 行动指令**

### 第 1 步｜痛点前置

把「我有什么」换成「你有什么麻烦」。买家不关心参数，关心参数解决的那件烦心事。

| 特性视角（弱） | 痛点视角（强） |
|---|---|
| 采用静音电机 | 夜里开着不吵醒同屋的人 |
| 316L 不锈钢内胆 | 泡了一夜的茶，第二天没铁腥味 |
| 续航 12 小时 | 出门一天，不用找充电口 |

**判定标准**：把句子里的产品名换成竞品名，如果这句话依然成立，说明没写出差异——痛点不够具体。

### 第 2 步｜场景代入

痛点必须落到一个**能被想象出来的具体时刻**。抽象的痛点不如一个画面。

- 差：适合上班族使用
- 好：早高峰地铁上，单手就能打开

场景三要素：**时间 + 地点 + 人的状态**。三者至少写实两个。

### 第 3 步｜证据支撑

每个主张后面挂一个可核验的东西：数据、检测报告、专利号、成分含量、认证编号。

**这里是硬约束：证据必须来自原稿或用户提供的信息。** 没有就写占位符：

```
【待补：SGS 检测报告编号】
【待补：续航实测数据，测试条件】
【待补：专利号】
```

占位符是**交付物的一部分**，作用是告诉用户「这句话现在不成立，需要你补什么」。**禁止编造任何数字、编号、机构名。**

### 第 4 步｜信任背书

背书由强到弱（按可核验程度排序）：

1. 第三方检测/认证（附编号）
2. 专利、资质证书（附编号）
3. 销量、复购数据（附来源与时点）
4. 品牌历史、产地产线
5. 用户真实评价（**不得编造**，不得用「用户都说好」这类模糊表述替代）

**禁用**：虚构的专家/医生推荐、明星同款（无授权）、「国家级」等未授权表述。

### 第 5 步｜行动指令

明确下一步做什么，机制必须真实：下单、领券、加购、咨询、试用装。**不得制造虚假紧迫感**（不实倒计时、虚假库存）。

## 二、FAB 转译

把技术特性翻译成买家利益的三级转换：

**Feature（特性）→ Advantage（优势）→ Benefit（利益）**

| F | A | B |
|---|---|---|
| 双层真空杯壁 | 保温性能优于单层 | 早上倒的热水，下午开会还是烫的 |
| 0.01 秒响应 | 延迟感几乎不可察觉 | 打游戏时手指一动画面就跟上 |
| 32 支精梳棉 | 纱线更细、更密 | 洗十次不起球，贴身穿不刺 |

**写法规则**：详情页正文以 B 为主，F/A 作为支撑出现在参数区。只堆 F 是规格书，不是文案。

## 三、句级改写手法

| 问题句型 | 病症 | 改法 |
|---|---|---|
| 「采用先进的 XX 技术」 | 「先进」不可验证 | 换成具体技术名 + 效果：`XX 双层过滤结构，过滤精度 0.1μm` |
| 「本产品具有以下特点」 | 主播式套话，零信息 | 直接删掉，从第一个卖点开始写 |
| 「满足您的各种需求」 | 「各种」无所指 | 列出 2-3 个具体需求场景 |
| 「品质卓越，做工精良」 | 形容词通胀 | 换可感知的描述：`接口处无缝焊接，摸不到毛刺` |
| 「行业领先的品质」 | 绝对化 + 空 | 删，或换为可核验的检测结论 |
| 长句套长句（40 字以上） | 阅读阻力 | 拆成 2-3 个短句，一句一个信息 |

**节奏建议**：详情页文案的目的性比文章强，句子宜短。卖点句控制在 **15-25 字**，一段不超过 **3 句**，段间留白。

## 四、两稿的产出要求

### 合规版

1. 逐条替换违规表述，**结构不动、卖点顺序不动**
2. 替换后句意与原句保持一致（不得顺手改观点）
3. 原句若无可替换方案（跨类功效宣称、医疗用语），**整句删除**并在改动表中标注「删除原因：不可改写」

### 优化版

1. 按五步法重排（痛点 → 场景 → 证据 → 背书 → 行动）
2. 可调整顺序、可合并、可删冗余，**但不得新增无据信息**
3. 保留原稿的所有**事实性**内容（参数、成分、规格、售后政策）
4. 若某卖点在原稿中缺证据支撑，保留位置并写占位符，不要静默删掉——用户需要知道这个卖点现在立不住

### 改动说明表（必出，不带即视为交付不合格）

| # | 原文 | 改后 | 类型 | 原因 | 依据 |
|---|---|---|---|---|---|
| 1 | 全网最低价 | 已删除 | 合规·删除 | 无据的比较级断言 | 《广告法》§9 |
| 2 | 顶级面料 | 意大利头层牛皮，厚度 1.2mm | 合规·替换 | 空断言换可验证事实 | 用户提供的材质说明 |
| 3 | 采用静音电机 | 夜里开着不吵醒同屋的人 | 优化·痛点前置 | 特性转利益 | — |
| 4 | 续航最强 | 续航 12 小时【待补：测试条件】 | 合规+占位 | 补条件，缺测试条件 | 《广告法》§28 |

## 五、过改反例（明确禁止）

**反例 1｜为降违禁词而删掉真实卖点**

原文：「通过 SGS 检测，甲醛释放量 0.02mg/m³（报告号 SHF2024XXXX）」
错误改写：「环保材质，健康安心」（把可核验的证据改成了空话）
正确做法：**保留原句**——它本身合规且是强证据，没有理由动它。

**反例 2｜为增强说服力而编造证据**

错误改写：「累计销量 100 万+」（用户没提供）
正确做法：写 `【待补：销量数据与来源】`。

**反例 3｜跨类升级**

原文（普通食品）：「富含膳食纤维」
错误改写：「促进肠道蠕动，改善便秘」（变成保健功能宣称）
正确做法：只保留成分事实，或改写为 `每份含膳食纤维 5.2g`。

**反例 4｜合规版被写成优化版**

用户在合规版里期待「改动最小」，却拿到一篇重写的文案，无法与原文对照审核。
正确做法：合规版**只动违规处**，其余一字不改。

**反例 5｜用规避手段处理违禁词**

把「最好」写成「zui 好」「最👍好」「蕞好」——**本技能明确不做**，见 SKILL.md 硬约束第 4 条。

- [ ] 两稿都已产出，且差异清晰可辨
- [ ] 所有 🔴 高危项已删除或改写
- [ ] 所有 🟠 中危项已补证或标注待补
- [ ] 品类必备提示语已加入（保健食品的"本品不能代替药物"、医疗器械的批准文号等）
- [ ] 无任何编造的数据、编号、机构、评价
- [ ] 改动说明表覆盖每一处变化
- [ ] 优化版每个卖点可回溯到原稿或用户提供的信息
- [ ] 未出现跨类功效宣称
- [ ] 强监管类目已提示走主管部门审查
