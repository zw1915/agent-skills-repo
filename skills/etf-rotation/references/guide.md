# ETF轮动配置助手 · 使用指南

## 输入
- 「用ETF做一个动量轮动」「股债怎么配比」「行业ETF怎么轮动」。

## 方案框架
1. 资产池定义（给出具体ETF示例：如 510300/中证500/创业板/黄金ETF/国债ETF）。
2. 信号选择（二选一或组合）：
   - 动量：过去3/6/12个月收益排序，取前N。
   - 估值：PE/PB历史分位，低配高、高配低。
3. 规则明确：调仓频率（月/季）、持有数量、权重（等权/风险平价）、单类上限（如≤40%）。
4. 风控：最大回撤阈值（如-15%降仓）、相关性约束。
5. 再平衡：固定日历 vs 偏离阈值触发。

## 输出必含
- 当前信号表（资产/信号/建议权重/备注）
- 回测要点（用朴素参数，避免过拟合话术）
- 执行节奏与风险揭示

## 边界
- 不承诺收益；提示模型风险；强调分散与纪律。
