# 法拍房平台清单与尽调清单（v2 配套）

## 一、主要房源平台（以官方/权威渠道为准）

| 平台 | 网址 | 特点 / 区域覆盖 |
|---|---|---|
| 淘宝/阿里资产·司法拍卖 | https://sf.taobao.com | 房源全国最多、信息全，支持按城市/板块筛选（**但筛选纯前端 JS，需浏览器才能按城市过滤**） |
| 京东司法拍卖 | https://auction.jd.com/sifa.html | 房源较多，常与银行不良资产联动（JS 动态，需浏览器） |
| 公拍网 | https://www.gpai.net | **上海及华东地区法院常用**，服务端渲染、可脚本直连（脚本 `fetch_gpai.py`）；**但实测 `q=城市` 搜索不按城市过滤**，返回全国混合流，需按法院/地区人工筛。长沙法院基本不挂，衡阳仅耒阳等少量，不能作为长沙/衡阳主源 |
| 人民法院诉讼资产网 | https://www.rmfysszc.gov.cn | 全国法院诉讼资产统一发布平台（最权威，但筛选 AJAX + WAF，需浏览器） |
| 中国拍卖行业协会 | https://www.caa123.org.cn | 拍卖机构与公告汇总 |
| 各城市不动产登记中心 / 法院官网 | 各地不同 | 公告原文、确权信息最权威 |

> 提示：所有"捡漏"判断最终必须以**法院发布的《拍卖公告》《竞买须知》《标的物调查情况表》**原文为准，第三方平台可能滞后或省略瑕疵说明。

## 二、折价率怎么看

- **折价率 = (评估价 − 起拍价) / 评估价**
  - 一般起拍价为评估价的 70%~80%，即折价 20%~30% 是常态。
  - 折价 ≥30% 且风险可控 → 真正的"捡漏"候选。
  - 二拍起拍价通常在一拍基础上再降 20%，折价更大但流拍/瑕疵概率也更高。
- 若公告未给评估价，可用「市场价/询价」近似替代计算折价（本技能评分脚本已支持 `--market` 兜底）。
- 额外要算：起拍价之外还有**税费、可能补的出让金、欠缴物业费/水电、装修与腾退成本**。

## 三、尽调清单（逐项核对，缺一不可）

1. **占用与腾退**：空置 / 业主自用 / 出租 / 法院"不负责清场"。后两者是最大坑，优先避开"不清场"标的。
2. **租赁**：是否存在长期租约（买卖不破租赁），租约真假与剩余期限。
3. **税费承担**："各付"还是"买受人全付"？后者实际成本显著上升。
4. **土地性质**：划拨地过户常需补缴土地出让金，出让地相对干净。
5. **产权与抵押**：是否红本、有无多次抵押、是否被查封之外的其他权利限制。
6. **户口与学区**：原业主户口是否迁出、学区名额是否占用（各地政策不同）。
7. **房屋用途**：住宅 vs 商办，商办税费高、流动性差。
8. **欠费**：物业费、供暖、水电燃气等历史欠费由谁承担（通常买受人背）。
9. **能否贷款**：是否支持"法拍贷"，不支持则需全款参拍。
10. **悔拍后果**：未按时付款，保证金不退，且差额可能由原买受人补足。

## 四、常见"假捡漏"陷阱

- **表面折价大但不清场**：省下的房价全赔在腾退官司上。
- **划拨地 + 买家全付税费**：到手成本可能接近甚至超过市场价。
- **长租约（20 年）**：拍下后多年无收益、难收房。
- **凶宅 / 重大瑕疵未披露**：公告写"按现状拍卖"，风险自担。
- **悔拍**：冲动加价超过承受能力，保证金与差价损失惨重。

## 五、自取步骤卡（无浏览器 / 自动抓取受限时交用户）

### 淘宝司法拍卖（全国房源最多，首选）
1. 打开 https://sf.taobao.com
2. 搜索框输入城市名（如「长沙」「衡阳」），频道选「房产」
3. 左侧筛选：价格区间填 **0–30 万**（或你的预算）、状态选「进行中/即将开始」
4. 按"折价"或"开拍时间"排序，逐条记：标题 / 起拍价 / 评估价 / 开拍时间
5. 点进详情读《拍卖公告》原文，核对"已知瑕疵"（占用/税费/土地）

### 人民法院诉讼资产网（最权威，兜底核对）
1. 打开 https://www.rmfysszc.gov.cn → 项目中心
2. 标的类型=**房屋**，标的所在地=**湖南省 / 长沙市(或衡阳市)**，起拍价≤你的预算，状态=即将竞价
3. 以《拍卖公告》原文为准

### 公拍网（上海/华东/耒阳等）
1. 打开 https://www.gpai.net → 司法拍卖
2. 或直接用本技能脚本：`python scripts/fetch_gpai.py --city 衡阳 --max-price 30`

> 把上面任一平台导出的清单（**标题 / 起拍价 / 评估价 / 城市**）贴回对话，本技能用 `score_listing.py --batch` 立即排名并标注风险。

## 六、出价锚点公式（参考）

```
心理最高价 = 评估价 × (1 − 合理折价) − 预估额外成本
预估额外成本 = 买家承担税费 + 可能出让金 + 欠费 + 装修/腾退费
```
只在「心理最高价 > 起拍价」且尽调无重大风险时参拍；成交价逼近心理最高价即停手。
