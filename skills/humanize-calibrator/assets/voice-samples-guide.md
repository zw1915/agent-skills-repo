# 语料样本指南（Voice Samples）

让改写**贴合你的语感**，而不是贴合一个通用的「人味」标准。

> 注意：Skill 包只支持两级目录（根目录 / 二级目录 / 文件），因此样本不单独放目录，
> 而是**直接粘贴进校准档案的一个章节**。见下方「放哪里」。

## 放哪里

粘贴进校准档案：

```
~/.workbuddy/skills/humanize-calibrator/calibration-profile.md
```

在其中的「语料样本」章节里直接贴原文即可。样例：

```markdown
## 语料样本

### 样本 1 · 工作邮件（半正式、解释型）
（粘贴你的原文，800 字以内）

### 样本 2 · 朋友圈（口语、短句）
（粘贴你的原文）
```

也可以不建文件，直接在对话里把样本发出来——提取完特征后把结果写进校准档案，
原文不必留存。

## 放什么

最好用**没经过 AI 加工**的原文：

- 你写的工作邮件、周报、需求文档
- 你发过的朋友圈、微博、公众号段落
- 你在群里做的长回复（尤其是解释型的那种）
- 手写笔记的转录

## 放多少

- **2–3 份、合计 800–2000 字**就够了
- 宁要真实，不要多。一份被 AI 润色过的东西会污染整个语料

## 会提取什么

只提取**可观察的形式习惯**，不评判好坏：

| 提取项 | 用途 |
|---|---|
| 平均句长、短句频率 | 校正 D5 的判定基线 |
| 常用人称（我 / 我们 / 笔者 / 无） | 校正 D4 |
| 标点习惯（破折号、括号插入、省略号） | 保持个人节奏 |
| 段落长度习惯 | 避免强行拆段 |
| 高频口头词（如「说白了」「本质上」「其实」） | 保留个人语感标记 |

## 不会做的事

- **不会**模仿你引用的他人文章的风格
- **不会**复制作家的标志性表达
- **不会**因为语料里出现某个词就无条件保留它（黑名单词照样替换）

## 与通用规则的关系

语料对齐**优先于**通用改写处方。例如：如果你的习惯就是写长句，那么为了 D5 分数
硬塞短句是错的——此时 D5 的口径会改成「相对你本人基线是否有起伏」。

详见 `references/calibration.md` 第 4 节。
