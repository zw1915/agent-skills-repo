# AI 味模式库（Pattern Library）

本文件是词表与句式模板的唯一来源。`scripts/tone_scan.py` 中的词表与此保持一致；
修改词表时两处都要改，避免打分口径漂移。

---

## 1. 黑话词表（D2-1）

### 商业黑话 —— 多数语境下空转，建议替换

| 词 | 替换思路 |
|---|---|
| 赋能 | 说清「给了谁什么能力」：让客服自己改话术，不用等 IT |
| 抓手 | 说清「具体动作」：先从退款流程开刀 |
| 闭环 | 说清「流程从哪到哪」：从下单到收货全在系统里 |
| 沉淀 | 说清「留下了什么」：把这些判例写成 20 条规则 |
| 对齐 | 说清「谁和谁统一了什么」：产品和销售定死了报价区间 |
| 颗粒度 | 说清「细到什么程度」：按门店而不是按大区算 |
| 心智 | 说清「用户怎么想」：用户默认这个功能要收费 |
| 打法 | 说清「怎么做」：先用免费版铺量，再卖增值服务 |
| 组合拳 | 说清「哪几招」：降价 + 延长保修 + 送安装 |
| 底层逻辑 | 说清「真正的原因」：真正的原因是渠道返点比直营高 |
| 护城河 | 说清「别人抄不走的什么」：十年攒下来的供应商账期 |
| 生态位 | 说清「卡在谁的哪个环节」 |
| 拉通 | 说清「谁跟谁通了」 |
| 协同 | 说清「谁配合谁做了什么」 |
| 势能 | 说清「具体攒了什么」 |
| 飞轮 | 说清「哪一环带动哪一环」 |
| 复盘 / 抓手 / 落地 / 拉齐 / 打法 / 增效 | 同上，一律追问「具体指什么」 |

### 万能副词（D2-2）—— 多数可直接删除

极大地、显著地、有效地、充分地、深度地、进一步、持续不断地、不断地、日益、
大力、全面、切实、有力地、大幅度地、尤为、更加、愈发

> 删除测试：删掉之后句子变弱了吗？没有 → 它本来就不该在。
> 例外：「显著」在统计语境下（p<0.05）是术语，保留。

### 抽象名词（D2-3）—— 必须有具体指称才能留

价值、维度、层面、体系、机制、能力、链路、矩阵、生态、范式、路径、方法论、
模型、框架、策略、举措、要素、指标、抓手

> 判定：后面能不能接一个具体例子？不能 → 换成具体的东西。

### 形容词通胀（D2-4）

非常重要、极其关键、至关重要、核心中的核心、重中之重、意义重大、前所未有的、
颠覆性的、革命性的、开创性的

> 处理：要么给证据（为什么重要），要么删掉。

## 2. 结构模板（D1 / D6）

### 2.1 背景起手式（D6-1）

- 随着……的发展 / 随着……的不断深入
- 在……的大背景下 / 在当今……的时代
- 近年来，……越来越受到关注
- 众所周知，……
- 在信息化/数字化/智能化浪潮下

**改法**：删掉整句，直接写第一个具体事实。

### 2.2 万能递进（D6-2）

- 不仅……而且…… / 不仅……还……
- 既……又……
- 一方面……另一方面……
- 既要……也要……

**改法**：多数情况下两句各说各的，中间不加连接词。真需要递进时用「更」或「而且」
这种轻连接。

### 2.3 升华收尾（D6-3）

- 综上所述 / 总而言之 / 总的来说
- 让我们一起…… / 相信在不久的将来……
- 只有这样，才能……
- 希望对您有所帮助 / 如有疑问，欢迎交流

**改法**：删。停在最后一个具体事实或一个动作上。

### 2.4 提示型过渡（D6-4）

- 值得注意的是 / 需要强调的是 / 尤其需要指出的是
- 不得不说 / 不可否认
- 换句话说（真需要解释时才用）

**改法**：删掉过渡词，直接写下一句。读者不需要被告知「注意了」。

### 2.5 设问自答（D6-6）

- 那么，××是什么？××就是……
- 为什么……？因为……
- 什么是××？简单来说……

**改法**：连续两次以上就必须改。允许一处，多了就是模板。

### 2.6 机械序号（D1-1）

首先 / 其次 / 再次 / 最后 / 第一 / 第二 / 第三 / 其一 / 其二

**改法**：论述文里用语义连接替代编号；操作步骤里保留编号。

## 3. 正反示例对照

### 示例 A · 商业分析

**AI 原稿**

> 随着数字化转型的不断深入，企业越来越重视数据资产的价值挖掘。
> 首先，企业需要建立完善的数据治理体系，夯实数据基础。
> 其次，要构建统一的数据中台，实现数据的拉通与协同。
> 最后，通过数据赋能业务，形成数据驱动的闭环，持续提升经营效率。
> 综上所述，数据资产已成为企业的核心竞争力，只有做好数据治理，才能在激烈的市场竞争中占据优势。

- 命中：D1-1（首先其次最后）、D2-1（赋能/拉通/协同/闭环）、D6-1（随着）、D6-3（综上所述）、D3-1（零数字）、D4-1（无立场）、D7-4（正确但无用）
- 问题本质：**四句话说了四件都对的事，但没有任何一句是这家公司明天能做的。**

**校准后**

> 大部分公司的问题不是没有数据，是同一份数据在三个系统里对不上。
> 财务看到的是上周五的库存，仓库系统里是昨天下午的，销售手上的报表又是另一个数。
> 每次对账，三个人花两天。这种事没法用「数据治理体系」解决，得先决定谁说了算。
> 我见过做得最有效的一招很土：让财务、仓库、销售三方每周一上午坐一起核一次数，
> 连续核三个月，把每次对不上的原因写下来。三个月后他们攒了 47 条原因，
> 其中 31 条是同一个字段的定义不一样。
> 【待补：请补充一个你所在行业的真实数据不一致案例，以及涉及的具体系统名称】

- 修复：加了具体场景与数字、给出可执行动作、明确表态、无套话
- **注意**：原文没有具体案例，所以用了占位符，没有编造

### 示例 B · 产品介绍

**AI 原稿**

> 本产品是一款极具创新性的解决方案，旨在为用户提供高效、便捷、智能的使用体验。
> 它具有三大核心优势：一是性能卓越，二是操作简便，三是安全可靠。
> 无论您是个人用户还是企业客户，都能从中获得极大的价值。
> 我们相信，本产品将成为您工作与生活中不可或缺的得力助手。

- 命中：D2-4（极具创新性）、D2-3（解决方案/体验/价值）、D1-1（一是二是三是）、D3（无数字无专名）、D4-6（无论……都能）、D6-3（我们相信）

**校准后**

> 这个工具只做一件事：把会议录音变成待办清单。
> 45 分钟的会，3 分钟内出结果，识别错的概率大约是每 20 条错 1 条，需要人工校一遍。
> 它不生成会议纪要，不做发言统计，也没打算做——市面上已经有一堆工具在做那些。
> 如果你每周开 10 场会、每场会后要花 15 分钟整理，这个东西一周能还你 2 个多小时。
> 如果你的会不开录音，它帮不上忙。

- 修复：说清了具体做什么、给数字、给代价（会出错）、**明确说出不适用场景**
- 这是「信息增量」维度的最佳示范：不适用场景比优点更能建立信任

### 示例 C · 观点表达

**AI 原稿**

> 关于远程办公，一方面它能够提升员工的工作灵活性，降低企业的办公成本；
> 另一方面，它也可能带来沟通效率下降、团队协作困难等问题。
> 因此，企业应当根据自身实际情况，因地制宜地制定远程办公政策，
> 在效率与体验之间找到平衡点。

- 命中：D4-2（骑墙）、D4-6（因地制宜/根据实际情况）、D7-5（无取舍）、D2-3（平衡点）
- 问题本质：**读完不知道作者到底怎么想。**

**校准后**

> 远程办公对 5 人以下的团队几乎全是好处，对 30 人以上的团队全是麻烦，中间地带看行业。
> 差别不在沟通效率，在「新人怎么学会那些没人写下来的事」。
> 10 人以内，新人坐旁边看两周就会了；50 人的团队，新人三个月还在问基本问题，
> 因为没人有空一直带着。
> 所以我的判断很简单：招人密集期回办公室，业务稳定期放开远程。
> 【待补：可替换为你自己团队人数与招聘节奏的真实经历】

- 修复：明确表态 + 给出条件分界 + 指出真正的变量

### 示例 D · 反例：过改（人味 ≠ 网感）

**错误示范（不要在改写中产出这种）**

> 家人们谁懂啊😭 这个工具真的绝绝子！！用了以后我整个人都升华了✨✨
> 真的会谢，以前我怎么没发现它呢🤣 冲就完事了！

- 问题：这是**表演性口语**，不是人味。堆 emoji、网络流行语、情绪空转，
  信息量与示例 A 的原稿一样是零，但可信度更低。
- 判定：HI 不会因此升高，D2（空泛）与 D7（信息增量）反而更差。
- **本技能明确禁止此类改写。** 详见 `calibration.md` 的过改护栏。

## 4. 扫描脚本使用的正则模板

以下模式在 `scripts/tone_scan.py` 中以正则实现，用于客观计数：

| 编号 | 模式 | 说明 |
|---|---|---|
| SEQ | `首先.{0,40}?其次` / `第一.{0,30}?第二` / `最后` | 序数连用 |
| BG | `随着.{0,20}?(发展|深入|推进)` / `在.{0,15}?背景下` | 背景起手 |
| SUM | `综上所述` / `总而言之` / `总的来说` | 升华收尾 |
| NOTICE | `值得注意的是` / `需要强调的是` / `不得不说` | 提示型过渡 |
| QA | `那么，.{0,20}?是什么？` | 设问自答 |
| ADV | 万能副词表 | 副词通胀 |
| JARGON | 黑话词表 | 黑话密度 |
