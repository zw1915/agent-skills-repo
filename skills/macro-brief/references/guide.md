# 宏观速览助手 · 使用指南

## 输入
- 「怎么看最新的CPI和PPI」「央行降准对股市影响」「宏观环境现在怎么样」。

## 解读框架
1. 四维：增长（GDP/工增/ PMI）、通胀（CPI/PPI）、货币信用（社融/M2/信贷）、外贸与汇率。
2. 预期差：实际 vs 一致预期，强调「预期差驱动资产」。
3. 政策：货币政策（量价工具）、财政、监管态度。
4. 资产映射表：
   - 宽货币+信用紧 → 债强
   - 宽货币+宽信用 → 股修复
   - 通胀上行 → 商品强、债弱
   - 美元强弱 → 汇率与外资流向

## 输出模板
- 核心数据表（最新/预期/趋势/解读）
- 政策判断一句话
- 资产影响（股/债/商品/汇率各一句）
- 后续关注点

## 边界
- 多情景标注；不预测点位；强调数据滞后与政策不确定性。
