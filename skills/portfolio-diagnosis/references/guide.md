# 持仓诊断助手 · 使用指南

## 输入
- 「帮我看看我的持仓」「这个组合风险大吗」「该怎么再平衡」。
- 用户应提供：标的、市值/占比、成本（可选）。

## 诊断维度
1. 集中度：前三大持仓占比（>50% 偏高）。
2. 行业/风格暴露：是否集中在单一行业或成长/价值一端。
3. 资产类别：股/债/商品/现金/海外比例。
4. 相关性：高相关标的合并视为单一风险。
5. 绩效与风险：收益率、波动、最大回撤、夏普（有数据则算）。

## 输出模板
- 结构表（标的/占比/行业风格/相关性备注）
- 三个风险点（按严重度排序）
- 再平衡建议（目标配比 + 具体调整）
- 执行注意（税费、节奏）

## 边界
- 无真实持仓只给框架；不承诺收益；强调分散与纪律。
