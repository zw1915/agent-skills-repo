# 市场情绪周期助手 · 使用指南

## 输入
- 「现在市场情绪怎么样」「恐贪指数到多少了」「是不是冰点」「赚钱效应如何」。

## 指标体系
1. 广度：涨跌家数比、涨停/跌停家数。
2. 量能：两市成交额、换手率（地量/天量信号）。
3. 资金：北向净流入、融资余额变化。
4. 综合：恐贪指数（0~100）。

## 五阶段定位
- 冰点：地量、普跌、恐贪<20 → 试错布局
- 回暖：放量企稳、涨停增多 → 跟随
- 活跃：赚钱效应扩散 → 持有
- 沸腾：天量、全面亢奋、恐贪>80 → 防守
- 退潮：缩量分化 → 降仓

## 输出模板
- 情绪评分 + 阶段
- 四项信号快照
- 策略基调（一句话）+ 观察信号

## 边界
- 指标有噪声与滞后；不预测拐点；强调逆向纪律。
