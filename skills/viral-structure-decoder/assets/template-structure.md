# 可复用结构模板 · 〔平台〕·〔结构原型名〕

> 用法：把【】里的内容换成你的选题。🔁 标记的位置必须换，🔒 的保留，
> ⚖️ 的按需替换。填完即可直接写。

---

## 一句话说明

用 **〔钩子类型〕** 抓注意力，靠 **〔承诺类型〕** 留人，以 **〔情绪落点〕** 收尾。

---

也是大多数模仿者会漏掉的一层。

## 三、填空版正文

```
【标题】
  〔人群词〕+〔时间 / 成本〕+〔获得结果〕+〔情绪钩子〕

【开篇 · 钩子】
  〔一句话说出读者的处境，或给一个反常识判断〕

【承诺 / 信任状】
  〔为什么可以听我的：身份 / 数据 / 结果，1–2 句，可省略〕

【信息点 1】
  〔结论 + 一句理由〕

【信息点 2】
  〔结论 + 一句理由〕

【信息点 3】
  〔结论 + 一句理由〕

【中段峰值】
  〔全文最有冲击力的一句：一个对比 / 一个数字 / 一个反转〕

【收尾 / CTA】
  〔按平台选一种：收藏 / 关注 / 评论关键词 / 提问 / 转发〕
```
