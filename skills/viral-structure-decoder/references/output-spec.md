# 输出规格（Output Spec）

## 1. 固定交付五项

| # | 交付物 | 必需内容 |
|---|---|---|
| 1 | 来源与平台判定 | 平台、内容形态、抓取方式、是否取得全文、未获取字段清单 |
| 2 | 结构扫描数据 | 脚本输出的硬指标：标题构成、钩子类型、段落节奏、小标题间隔、金句候选、CTA |
| 3 | 逐层拆解 | 按平台框架分层，每层含「手法 / 位置 / 为什么有效」 |
| 4 | 可复用结构模板 | 填空式，含骨架、变量、适用范围、风险提示 |
| 5 | 二创询问 | 三个明确选项 |

**顺序不可调换。** 模板必须建立在拆解之上，不能跳过拆解直接给模板——
那样给出的模板是通用套路，不是「从这条拆出来的」。

---

## 2. 「可复用结构模板」的必需组成部分

这是主交付物。缺任一部分视为不合格。

### 2.1 一句话说明

用一句话说清这个结构的运转方式，格式：

> 用 **〔钩子类型〕** 抓注意力，靠 **〔承诺类型〕** 留人，以 **〔情绪落点〕** 收尾。

例：用「成本量化」抓注意力，靠「我也能做到」的可行性留人，以「释然」收尾。

### 2.2 骨架表（逐段功能标注）

| 位置 | 功能 | 原内容手法 | 你要填什么 |
|---|---|---|---|
| 标题 / 封面 | | | |
| 第 1 句 | | | |
| 第 2–3 句 | | | |
| 第 1 个小标题 / 第 1 个信息点 | | | |
| 中段峰值 | | | |
| 收尾 | | | |

要求：**必须标出「中段峰值」在哪**——这是大多数拆解漏掉的一层，
也是决定内容能否被记住的关键位置。

### 2.3 可替换变量表

| 变量 | 性质 | 原内容（仅作示例） | 换成你的 |
|---|---|---|---|
| 主题 / 选题 | 🔁 必须换 | | |
| 目标人群 | 🔁 必须换 | | |
| 具体事实、案例、数据 | 🔁 必须换 | | |
| 个人经历 | 🔁 必须换 | | |
| 钩子类型 | 🔒 建议保留 | | |
| 结构原型 | 🔒 建议保留 | | |
| 段落数量与节奏 | 🔒 建议保留 | | |
| 情绪落点 | ⚖️ 可有条件更换 | | |
| CTA 类型 | ⚖️ 按平台适配 | | |

🔁 必须换 / 🔒 建议保留 / ⚖️ 有条件更换 —— 三档标记不可省略，
它直接告诉用户哪些能改、哪些改了结构就散了。

### 2.4 适用与不适用范围

两栏都要写。只写「适用」的模板会让用户误用在错误场景上。

- **适合**：什么类型的选题、什么阶段的账号、什么平台
- **不适合**：什么情况会失效（例：需要真实案例支撑，无案例会显得空）

### 2.5 风险提示

写出这个结构的**短板**，至少一条：

- 依赖稀缺素材（无素材撑不起来）
- 结构性套路重，多次使用会被识破
- 情绪强度高，不适合严肃选题
- 需要特定身份背书（无身份则信任状缺失）

### 2.6 填空版正文

最后给一份可以直接改的骨架，用【】标出填空位：

```
【标题】〔人群词〕+〔成本/时间〕+〔结果〕+〔情绪钩子〕
【开篇】〔钩子句〕
【第 1 段】〔信任状或背景，1–2 句〕
【信息点 1】〔结论 + 一句理由〕
【信息点 2】〔结论 + 一句理由〕
【峰值】〔最有冲击力的一句/一个对比〕
【收尾】〔CTA〕
```

## 3. 合规边界细则

### 3.1 可复用层 vs 不可复用层

| 层 | 内容 | 可否复用 |
|---|---|---|
| **结构层** | 钩子类型、结构原型、段落功能、节奏、CTA 类型、情绪曲线 | ✅ 可以，鼓励 |
| **表达层** | 句式模板、修辞类型（非原句） | ✅ 可以 |
| **内容层** | 具体事实、数据、案例、个人经历、原创观点、独家信息 | ❌ 不可以 |
| **原创表达** | 标志性句子、金句原句、独特比喻 | ❌ 不可以直接搬 |

### 3.2 判定标准（自查）

拆解后、二创前，问一句：

> **把结构层保留、内容层全换掉之后，成品和原文还像同一篇文章吗？**

- 不像 → 合规，是结构复用
- 仍然像 → 说明内容层没换干净，需要拉开距离

### 3.3 引用规范

- 引用原文**仅用于举证**，在引用处标注「原文摘录」
- 单次引用控制在必要长度（举证够用即可），不做大段转载
- 报告开头标注来源链接与作者（若可见）

### 3.4 明确拒绝的情形

| 请求 | 处理 |
|---|---|
| 「帮我改成伪原创，别让平台判重」 | 拒绝，说明这属于洗稿；可改为提供结构模板供其自己写 |
| 「把他的文章换几个词发出去」 | 拒绝 |
| 「用这篇的独家数据写一篇」 | 拒绝；数据属原文作者，可改为「可引用并注明出处」 |
| 「照这个结构写」 | ✅ 正常执行 |

拒绝时给出替代方案，不要只说「不行」。

## 4. 二创衔接

模板交付后主动询问，**一次问全，不要挤牙膏**：

1. **新选题是什么？** 主题 + 目标人群
2. **还是发同一个平台吗？** 平台不同则要换拆解框架（例：小红书结构直接搬到知乎会失效）
3. **结构强度选哪个？**
   - A 完全照骨架（最稳，最像原版）
   - B 保留骨架、只换钩子类型（推荐，个性与稳定兼顾）
   - C 只借情绪曲线，结构自己搭（上限高，风险高）
4. **你手上有什么真实素材？** 经历 / 数据 / 案例 / 对话记录
   —— 没有真实素材时，二创会出现「结构在、内容空」的问题，
   此时应主动提醒并列出待补清单，而不是编造素材
5. **语气强度？** 原版偏理性还是偏情绪，你要哪一个

---

## 5. 输出质量自查清单

交付前逐条确认：

- [ ] 每一层拆解都指出了**具体位置**（第几句 / 第几段），而非笼统评价
- [ ] 钩子类型用模式库里的**标准名称**命名，不是自造描述
- [ ] 结构原型判定到具体一种（如「递进式」），不是「比较清晰的结构」
- [ ] 模板含「中段峰值」位置
- [ ] 变量表用 🔁/🔒/⚖️ 标注了可改与不可改
- [ ] 写了「不适用」范围，不只是「适用」
- [ ] 至少一条风险提示
- [ ] 未获取的字段如实标注，没有编造
- [ ] 引用了原文的地方标了来源
- [ ] 结尾有明确的三选一二创询问
