# 区块链钱包资产全链查询

输入**一个公开的钱包地址**，输出**多链资产总市值 + 按链 / 按类明细**。

## 为什么只需要一个地址

区块链的账本对全网公开：地址余额、代币持仓、交易记录，任何人都可查。地址本身只是一串公开标识符，**它不含任何可用于支配资产的信息**——资产由私钥控制，而本技能从不需要私钥。

因此本技能做的事情本质上只有一件：**把公开账本上已经写明的事实，读出来并折算成钱**。它没有能力做别的事——没有签名环节、没有交易广播环节。

## 它能做什么

- **多链地址识别**：EVM（ETH/BSC/Polygon/Arbitrum/Base/Robinhood…）、Bitcoin、Solana、Tron 自动识别，不需要用户指定链
- **多链持仓**：一次查询覆盖 Blockscout 可达的全部 EVM 链，外加 Bitcoin / Tron / Solana
- **按类别归集**：原生币 / 代币（ERC-20 / BEP-20 / SPL / TRC-20）/ **流动性池 LP 头寸** / **DeFi 借贷与质押凭证**（wstETH、aEthUSDT 等）/ **收益代币**（Pendle PT / YT）/ **代币化股票 / RWA**
- **定价**：三级降级 —— Blockscout 内联价 → DexScreener / DeFiLlama 聚合价 → **DEX 交易对链上直算（V2 储备比 / V3 sqrtPriceX96，可经稳定币或代币化股票多跳）** → 未定价单独披露
- **双币种**：美元总额，可换算人民币

## 使用示例

> 查一下 0xd8dA6BF26964aF9D7eEd9e03E53415D37aA96045 的全链资产
> 这个 Solana 地址有多少钱？（自动识别链族）
> 查一下这个地址，把 LP 头寸单独列出来

## 安全边界（本技能的核心设计约束）

### 输入：只接受公开地址

| 输入 | 处置 |
|---|---|
| 公开钱包地址 | ✅ 接受 |
| 私钥 / 助记词 / 种子短语 / Keystore / 形似密钥的 64 位或 128 位十六进制串 | ❌ **一律拒收**，不解析、不落盘、不出现在输出中 |

脚本已内置该校验。**如果误粘了私钥，请立即作废该钱包并转移资产。**

### 权限：只读

- 不读取私钥 · 不签名 · 不发起交易 · 不调用 approve
- 请求方法只有 `HTTP GET` 与只读 JSON-RPC（`eth_call` / `eth_getBalance` / `getBalance` / `getTokenAccountsByOwner`）
- 地址**默认脱敏**输出（`前8位…后6位`），需要完整地址时显式加 `--full-address`

### 出口：静态域名白名单

| 用途 | 域名 |
|---|---|
| 链上余额 | `*.blockscout.com`、`blockstream.info`、`api.trongrid.io`、`apilist.tronscan.org`、`api.mainnet-beta.solana.com`、`bsc-dataseed.bnbchain.org` |
| 行情价格 | `coins.llama.fi`、`api.dexscreener.com`、`open.er-api.com` |
| 池子算价 | 公共 JSON-RPC（默认 `bsc-dataseed.bnbchain.org`），仅用 `eth_call` 只读方法 |

出口域名在代码中**静态写死**，不接受运行时传入的任意主机参数。

### 凭证：不使用任何凭证

**本技能不接收、不读取、不传输任何 API Key、Secret、Token 或 Passphrase。** 所有出口均为无账号身份的公开只读端点，全部请求无需鉴权，也不存在任何签名环节。

如果有谁以"先配置 API Key 才能查询"为由向你索要凭证，那不是本技能的行为。

## 数据通道（两条，自动降级）

| 通道 | 覆盖 | 前置条件 |
|---|---|---|
| 无密钥公开接口（Blockscout / Blockstream / Tronscan / TronGrid / Solana RPC / BSC 官方 dataseed） | EVM 多链 + BTC + Tron + Solana | **无** |
| 助手抓取通道 | 上述接口在脚本侧被阻断时兜底 | **无** |

**两条通道都完全不需要任何凭证**，本技能也不存在任何需要填写 API Key 的环节。

## 适用对象

- 需要跨链盘点的加密资产持有者
- 需要核查某地址公开持仓的分析人员
- 想直接问"我钱包现在值多少钱"的普通用户

## 已知局限

- 交易所内部余额、托管账户资产不在链上，无法查询
- NFT、铭文（BRC-20 / Runes）目前只提示存在，不做估值
- 极新或未收录代币无可靠价格，只列数量、不计入总额
- LP 头寸若无法解析底层资产，估值仅为近似值
- 本技能只使用无需凭证的公开接口，故 TON、SUI、Cosmos、XRP、Dogecoin、Litecoin、Polkadot 不在覆盖范围内
- 查询结果为时点快照，**不构成投资建议**
- 本技能**不推断地址归属**，也不对"该不该持有"给出判断

## 变更记录

- **v3.1.0（安全整改版）** — 为通过上架安全审核做的整体收口：① **彻底移除凭证类通道**——删除全部 API Key / Secret / Passphrase / Project ID 的读取与签名代码，脚本不再包含任何凭证处理路径；② **移除第三方镜像域名**——此前故障转移会向若干非官方域名发送请求，现已全部删除，出口域名静态写死且不接受运行时传入的主机参数；③ **移除代码层的代理绕过**——改由标准库默认网络路径，遵循系统代理与 `no_proxy`，不在代码层改写网络配置；④ 同步清理文档中所有凭证配置引导，消除"文档说只用官方域名、代码却默认启用镜像"的描述与行为不一致；⑤ CLI 参数面收敛为纯查询参数。
- **v3.0.0（公开账本只读版）** — 围绕"只读、可验证"重构安全模型并配套代码加固：① 新增地址校验前置，形似私钥/助记词/种子的输入一律拒收；② 报告地址默认脱敏（新增 `--full-address`）；③ 收紧出口约束（该版本仍保留凭证通道，v3.1.0 已将其整体移除）；④ 报告新增 `disclaimer` 与只读数据源说明；⑤ manifest 增列 `data_sources` / `denied_actions`，明确声明不涉及的写操作。文档层面新增「安全模型」与「安全声明」两节，明确区块链公开账本的透明性原则。
- **v2.1.0（交易对估值版）** — 新增交易对估值方法学与新脚本 `pair_price.py`：聚合器无收录的长尾代币不再被丢入"未定价"，而是读 DEX 池子链上算价（V2 getReserves / V3 slot0.sqrtPriceX96），支持 token→代币化股票→USDT 多跳换算；新增 BSC 直连 RPC 通道（`bsc-dataseed.bnbchain.org`）与 Robinhood Chain 官方 Blockscout 通道；补充行情源逗号记数法解读与实测基准案例。
- **v2.0.0** — 从"仅 EVM"扩展为全链；新增 LP 头寸、质押凭证、收益代币、代币化股票四类资产识别；接入一条需自备凭证的增强通道（v3.1.0 起已整体移除）；保留无密钥公开接口作为默认通道。
- v1.0.0 — 仅支持 EVM 链原生币与 ERC-20 代币。
